}
Expand description

A low-level, unchecked view into contiguous subsequence of a collection.

NOTE: The trait doesn’t enforce usual lifetime tracking. It is intended to be wrapped in a safe view (i.e., Slice).

It is responsibility of caller to provide such 'a that doesn’t violate memory safety.

Returns a slice of elements in position range [from, to).

It is responsibility of caller to use this mechanism to create disjoint slices of appropriate lifetimes.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
